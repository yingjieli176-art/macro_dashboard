# Macro Dashboard · V1.0

## 本地运行

使用 Python 3.12，数据源刷新需要网络连接。

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

需要的密钥应通过部署平台 Secrets 或本地 `.streamlit/secrets.toml` 配置，不能提交到仓库。依赖版本以 `requirements.txt` 为准。

## 更新与数据口径

数据采集由现有 GitHub Actions 定时任务执行，无需每天在聊天中要求更新。发布流程保留校验、失败保留最近有效快照和并发推送保护。定时任务成功不代表每条曲线都已到最新观测日；以页面标注的实际观测日期和源审计为准。

缺数保留缺失，不通过插值、虚构值或修改观测日期补齐。收益率、成交利率、政策利率与工具用量分别处理。日本图的上下沿是适用范围内的政策参考，不是所有交易的绝对边界。

## 验证与继续维护

```bash
python -m pip install pytest
python -m pytest tests -q --tb=short
```

`Dashboard regression` 集中运行应用回归；浏览器、数据源和版本恢复另行验证。V1.0 已通过384项测试及249个子测试，但完整浏览器验收仍有手机端多轴图宽度问题，部分源数据也有时效告警。详见项目状态，不把这些问题标为已解决。

日常开发从最新 `main` 建立功能分支。归档分支用于保存交接快照，不作为后续自动数据发布目标。
